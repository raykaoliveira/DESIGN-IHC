# Sketches – Protótipos de Baixa Fidelidade

## 01. Introdução

Nesta etapa, são apresentados os protótipos de baixa fidelidade (sketches) desenvolvidos para representar as principais telas do sistema **GAPI**.

Os sketches têm como objetivo materializar visualmente as soluções propostas durante a etapa de ideação, permitindo analisar a organização dos elementos da interface e explorar diferentes possibilidades de design antes da elaboração de protótipos mais detalhados.

A construção das telas considera os princípios de **Usabilidade, Comunicabilidade e Experiência do Usuário (UX)**, buscando proporcionar interações claras, eficientes e adequadas às necessidades dos usuários.

## 02. Ferramenta Utilizada

Os protótipos foram elaborados utilizando a ferramenta **Draw.io**, que permite representar visualmente os elementos da interface por meio de esboços de baixa fidelidade.

Nesta etapa, as telas não possuem funcionalidades interativas, sendo utilizadas para representar a estrutura inicial da interface e apoiar a análise das soluções propostas.

## 03. Apresentação dos Sketches

Os sketches foram organizados de acordo com as funcionalidades definidas nos diagramas HTA e MoLIC. Cada representação busca demonstrar a estrutura das telas, os elementos necessários para a realização das tarefas e os caminhos de interação disponíveis aos usuários.
